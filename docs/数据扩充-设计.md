# ArtAgent 本地数据扩充设计（Stage 7 前置）

> 状态：设计定稿（2026-08-02，与用户讨论确认）
>
> 背景：本地核心库只有 SemArt（21,384 幅 8–19 世纪欧洲绘画 + 评论体 DESCRIPTION），
> 断代窄、媒介单一、无画家生平/流派本体/馆藏信息。本设计解决"本地库缺什么、从哪拿、怎么进系统"。

## 1. 总体架构：本地核心集 + 实时 API 增量

```
本地核心库（精选、有描述、能语义检索）     实时 API（长尾 + 事实查证，独立工具）
  ├─ SemArt（现状不动，eval 基线锁定）      ├─ museum_search（Met 免 key / Rijksmuseum）
  ├─ 扩展画作库 dataset_id="extended"       ├─ wiki_lookup（Wikidata 实体事实）
  │    ├─ 全量记录表（结构化，exact_lookup）└─ web_search（时效信息：展讯/新闻）
  │    └─ 有描述子集 → BGE 向量 collection
  └─ 用户文档（PDF 双路 / 表格，Stage 3/5 已就位）
```

分工原则：
- **本地 = 高价值精选集**：有描述、有图、能语义检索、能支撑 timeline/recommendation 的确定性编排
  （group_by_axis 必须在本地全量数据上做，API 给不了）。
- **API = 长尾覆盖 + 实时信息**：任何作品可查元数据；不本地化、不进向量。
- **描述文本是本地化的判据**：有描述才向量化，没描述只进表。

## 2. Schema 定稿（扩展画作表）

> 列名全部小写英文；Chroma metadata 只接受标量（str/int/float/bool），无嵌套。

| 列 | 类型 | 说明 |
|---|---|---|
| `object_id` | str | 跨源稳定 ID，形如 `aic:28560`；Chroma id 直接用 |
| `title` | str | 标题 |
| `artist` | str | 艺术家显示名（如 `Vincent van Gogh`） |
| `year_start` / `year_end` | int? | 数值年份（过滤用） |
| `year_display` | str | 原始年代显示（如 `1889` / `c. 1607`） |
| `year` | int? | 派生：`year_start`（排序/范围过滤） |
| `year_bucket` | str | 派生：50 年桶（`1851-1900`），timeline 的 `group_axis_col` |
| `medium` | str | 材质（如 `Oil on canvas`） |
| `school` | str | 流派/运动（如 `Post-Impressionism`；缺省由 Wikidata 画家级继承） |
| `description` | str | **唯一进向量的字段**；HTML 清洗后存 |
| `image_url` | str | 图片 URL（`image_lookup` 需扩展支持 URL） |
| `license` | str | 版权记录（如 `CC0/Public domain (AIC)`） |
| `dimensions_raw` | str | 原始尺寸文本 |
| `width_cm` / `height_cm` | float? | 派生：解析出的厘米尺寸 |
| `location` | str | 现藏地（如 `Painting and Sculpture of Europe · Art Institute of Chicago`） |
| `source_api` | str | 来源（`aic` / `smithsonian` / `wikidata`） |
| `dedup_key` | str | 派生：`artist\|title\|year` 小写归一化，跨源去重用 |

**派生字段规则**：
- `year_bucket`：`(year-1)//50*50+1` → `{start}-{start+49}`（与 SemArt TIMEFRAME 同格式）。
- `dedup_key`：`"|".join([artist.strip().lower(), re.sub(r'\s+',' ',title).strip().lower(), str(year or "")])`。

## 3. 数据源组合与字段覆盖（实测确认）

| 字段 | AIC（主力） | 史密森尼（补充） | Wikidata（知识层） | MET（实时 API） |
|---|---|---|---|---|
| 标题/艺术家/年份/材质/尺寸/图片 | ✅ | ✅ | ✅ | ✅ |
| 流派/运动 | ✅ `style_title`（部分） | ❌ | ✅ 画家 movement 继承 | ❌ |
| 描述文本 | ✅ `description`（部分） | ⚠️ 部分 | ⚠️ 短描述 | ❌ |
| 现藏地 | ✅ 本馆 | ✅ 本馆 | ✅ collection（跨馆） | ✅ 本馆 |
| key/限流 | 无 key，60 req/min | 免费 key，限流待实测 | 无 key | 无 key |
| 授权 | 元数据 CC-BY 4.0，PD 图 CC0 | CC0 | CC0 | CC0（PD） |

**结论**：最少 3 个源可填满 §2 的表——AIC（作品+描述+流派）、史密森尼（美国艺术补充）、
Wikidata（流派继承 + 跨馆现藏地 + 别名 + 生平）。MET 不进本地库（无描述/无流派），留作 Stage 7 实时源。

### 描述补全顺序（决定向量化规模）
1. 原生描述：AIC / 史密森尼 / （将来）Rijksmuseum 展签文本；
2. Wikidata 短描述（免费）；
3. LLM 生成：仅限"知名作品 + 仍无描述"的精选集，抽样人工核验。

## 4. 构建管道（scripts/build_extended_dataset.py）

```
fetch（AIC 分页拉取 + 过滤：Painting & 有图 & 有描述）
  → map（§3 映射 + 派生字段）
  → CSV（data/extended/aic.csv，/data/ 已 gitignore）
  → index（有描述子集 BGE 向量化 → Chroma collection "extended"）
  → register（进程内注册 dataset_id="extended" + 检索冒烟）
```

纪律（承接 §13 陷阱速查）：
- 外部 API 客户端**显式超时 + 重试退避**（§1.5 教训）；AIC 60 req/min → 请求间隔默认 1.2s；
- `object_id` 作 Chroma id → 重复 index 天然幂等覆盖；
- 向量化只对有描述行，`index --dry-run` 可预览规模；
- 空描述行只进 CSV 不进向量（指名查询仍可用 exact_lookup/结构化路径）。

## 5. 运行时接入（下一步实施清单）

1. `src/retrieval/base.py`：`RetrievalSource` Literal 加 `"extended"`（及后续 `"smithsonian"`）；
2. `src/retrieval/structured_retriever.py`：`get_structured_retriever` 对 `extended` 懒注册
   （仿 `_register_semart`，`df_loader` 读扩展 CSV、`collection_loader` 取 `extended` collection）；
3. `src/retrieval/hybrid.py::get_hybrid_retriever`：注册 `source="extended"`；
4. `web/service.py::datasets()`：加 `{"dataset_id": "extended", "name": "扩展画作库（AIC）", "kind": "builtin"}`，
   前端切换器自动出现；
5. `src/tools/retrieval.py::_format_result`：加 `extended` 分支，输出契约
   `title / author=artist / date=year_display / image_file=image_url / description_snippet / source`；
6. eval 隔离：新源独立评测，不污染 semart 基线（§13 #12 不变）；
7. 史密森尼/Wikidata 接入时复用同一 loader 接口，仅替换 fetch 实现。

## 6. 验收

- 纯单测全绿：`tests/test_build_extended.py`（清洗/尺寸解析/去重键/字段映射/过滤条件）；

- 能力开关：`year_bucket` 存在 → `supports_timeline=True`；`description` 存在 → `supports_recommendation=True`；
