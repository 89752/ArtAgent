## 8. 结论与建议

1. **检索质量达标**：88% Recall@5 与历史最优持平，Jina API 精排可用且快。
2. **意图分类有明确短板**：comparison 全灭，优先修分类逻辑/阈值，预期可回到 88–90% 区间。
3. **Agent 行为评估被基础设施问题污染**：DashScope 免费额度耗尽 + 内容审核误判，导致 5/9 类行为与全部事实题无有效数据。结论前必须：① 充值或关闭免费模式；② 重跑 `agentic_eval.py` 与 `tool_eval.py`（后者已加单条异常保护）。
4. **工具选择已暴露真实问题**：知识问答的检索开关、技能选择、天气类联网兜底三类失败值得优先修。
