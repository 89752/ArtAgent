## E 组：常见异常对照

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 该直答却检索/调工具（A1–A3） | 路由/零工具回归 | 重跑 `--route`、`--tools`，贴日志 |
| 追问被反问（B3） | 指代/改写问题 | 贴 rewrite_split 日志；查 mt-002 回归 |
| 记忆不引用（B1/B5） | MEMORY_USER_ID 与 web_user 不一致 / 未落库 | 看 🧠 面板与 `/api/memory` |
| 推荐无理由或画作粒度不足 | 推荐链路 | 重跑 `--tools`，贴 final_answer |
| rerank 连续失败 | 代理/额度/旧进程 | 重启服务，贴 `[rerank]` 错误行 |
| 面板条目与对话对不上 | 旧数据残留/身份错位 | 确认已清空并重启后再测 |
